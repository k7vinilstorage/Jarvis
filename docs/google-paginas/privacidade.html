Política de privacidade do Jarvis

Última atualização: 25 de setembro de 2026.

O que é o Jarvis

O Jarvis é um assistente pessoal de uso privado, que roda num servidor doméstico do seu dono. Ele não é oferecido ao público. As únicas contas Google conectadas a ele são as do próprio dono.

Dados do Google que o Jarvis acessa

  • Endereço de e-mail da conta: para saber de qual conta vem cada informação.
  • Google Agenda: a lista de agendas e os eventos, para responder perguntas sobre compromissos. O Jarvis também cria eventos quando o dono pede e confirma.
  • Gmail, só leitura: remetente, assunto, data e trecho das mensagens, para resumir o que chegou. O Jarvis não envia, não apaga e não altera e-mails.

Como os dados são usados

Os dados servem só para responder às perguntas do próprio dono. Eles são processados no servidor dele, por um modelo de inteligência artificial que também roda localmente.

Os dados não são vendidos nem compartilhados com terceiros. Também não são usados para publicidade nem para treinar modelos de inteligência artificial.

Armazenamento

O servidor guarda o token de autorização de cada conta, num arquivo acessível só pelo serviço de ferramentas do Jarvis. As respostas do Jarvis podem ficar no histórico de conversas local, no mesmo servidor. Nada é enviado para servidores de terceiros.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Depois disso, o token guardado no servidor para de funcionar e pode ser apagado.
