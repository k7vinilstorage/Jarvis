Jarvis

O Jarvis é um assistente pessoal de uso privado. Ele roda num servidor doméstico e responde perguntas do próprio dono, por texto ou por voz.

Com a autorização do dono, ele consulta o Google Agenda para dizer os compromissos e criar eventos pedidos. Também consulta o Gmail, só para leitura, para resumir os e-mails recebidos.

Este aplicativo não é oferecido ao público e não tem outros usuários.
